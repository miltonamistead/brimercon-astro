# Technical SEO audit — 2026-09-22 (M3)

Verified against the staging build (`npm run build`, 56 pages). Each item maps
to `docs/technical-seo-checklist.md`.

## A. Indexing controls

- **Robots meta**: PASS. All 56 pages carry exactly one
  `<meta name="robots" content="noindex, nofollow">` (verified programmatically).
- **X-Robots-Tag**: declared in `vercel.json` (`noindex, nofollow` on `/(.*)`).
  Live-header proof needs the preview + bypass token (see staging notes below).
- **robots.txt**: PASS. `Allow: /`, `Disallow: /api/`, no `Sitemap:` line, with
  the staging comment.
- **Deployment Protection**: Vercel Authentication on all deployments of
  `brimercon-astro-staging`. No custom domain. Recorded in `docs/qa/staging.md`.
- **Sitemap**: PASS. Staging build ships none. An indexable test build
  (`PUBLIC_INDEXABLE=true`) produced 54 URLs: all 53 live URLs present, 0
  missing, plus `/service-areas/martis-valley/`. `/thank-you/`, `/api/*` and
  404 correctly excluded.
- **Canonical**: PASS. Every page has exactly one absolute canonical on
  `https://www.brimercon.com/<path>` with trailing slash.

## B. Titles, descriptions, headings

- **Titles**: `qa-links` diffs `<title>` per path against
  `docs/crawl/live-inventory.json`; no unexpected diffs (intentional ones are
  listed in `docs/url-map.md`).
- **Meta descriptions**: PASS. All 56 present, unique, and now ≤ 160 chars.
  Six were trimmed on 2026-09-22 (`/`, `/about/`, `/services/`,
  `/services/water-heaters/`, `/services/gas-services/`, `/membership/`);
  the `/request-service/` truncation noted in the checklist was already fixed.
- **One H1 per page**: PASS (56/56).
- **Heading order**: H2 sections, H3 in cards/FAQs; `qa-headings` enforces the
  H2 rules (length, sentence case, place ratio, no dashes).

## C. URLs and redirects

- Trailing slash: `vercel.json` `"trailingSlash": true`, `build.format:
  'directory'`.
- 301s declared in both `vercel.json` and `astro.config.mjs`:
  `/water-heater-services`, `/water-heater-services/`, `/sitemap.xml`.
  Preview `curl -I` proof still to do (needs bypass token).
- **No internal link to a 404**: PASS. `qa-links`: 56 pages, 2206 internal
  links, 0 failures.
- Internal links are root-relative; the only absolute
  `https://www.brimercon.com` hrefs are the canonicals (required).

## D. Structured data

- 128 JSON-LD blocks across 56 pages; all parse as JSON. Spot checks:
  `Plumber` with `#business` id, `Service`, `FAQPage`, `BreadcrumbList` with
  item URLs on every crumb, `BlogPosting` on posts. No `AggregateRating` or
  `Review` markup anywhere (audit H10).
- Rich Results Test spot-check on the preview is manual and still to do.
